# Network Traffic Analysis & Threat Detection

## Project Overview

This project focuses on analyzing network traffic to identify suspicious activities and understand potential security threats. The investigation is performed using Wireshark and other network security tools.

The main goal is to understand how network communication works and how unusual traffic patterns can help identify possible attacks.

## Task Information

- **Project:** Network Traffic Analysis & Threat Detection
- **Category:** Cybersecurity / SOC Analysis
- **Primary Tool:** Wireshark
- **Other Tools:** Kali Linux, TCPdump, VirusTotal

## Objectives

- Capture and analyze network traffic.
- Understand TCP, UDP, DNS, and HTTP communication.
- Identify suspicious IP addresses.
- Investigate unusual ports and network connections.
- Detect possible reconnaissance and scanning activities.
- Document observations and security recommendations.
